function c_print_err(msg: str) → null native

mocha-astro — Vedic Astrology (Jyotish) Computation Library for Mocha. Section 1: Ayanamsa & Sidereal Foundations. NOTE ON PRECISION: This library uses mean orbital elements and linear. ayanamsa models (the same approach as Meeus's "Astronomical Algorithms". and most pre-2000 astrology software), not VSOP87/JPL-grade numerical. ephemerides. Expect arcminute-level accuracy — sufficient for dasha,. varga, and aspect work, but not observatory-grade. Ayanamsa constants. are approximate mean models; exact values from Swiss Ephemeris-based. software may differ by a few arcminutes due to periodic correction terms. Part of the Mocha Scientific Library Ecosystem. License: Polyform Non-Commercial.

function julian_day_number(year: int, month: int, day: int, hour: float) → float

Julian Day Number from a Gregorian calendar date and UT hour. year, month, day = calendar date, hour = UT time as decimal hours (e.g. 12.5 = 12:30). Standard astronomical algorithm (Meeus). Reference: JD(2000-01-01 12:00 UT) = 2451545.0. Requires month in [1, 12], day in [1, 31], hour in [0, 24).

function fractional_year(year: int, month: int, day: int) → float

Decimal (fractional) year from a Gregorian calendar date. year, month, day = calendar date. E.g. 2024-07-04 -> ~2024.505. Requires month in [1, 12] and day valid for that month/year (leap-aware).

function normalize_degrees(angle: float) → float

Normalizes an angle in degrees to the range [0, 360). Works for any real input.

function lahiri_ayanamsa(year: float) → float

Lahiri (Chitrapaksha) ayanamsa in degrees for a given decimal year. Official ayanamsa of the Indian government. Linear mean model. Valid approximately for years 1800-2200; beyond that, the linear model drifts by arcminutes to degrees.

function raman_ayanamsa(year: float) → float

B.V. Raman ayanamsa in degrees for a given decimal year. Approximated as Lahiri ayanamsa with documented constant offset. Same valid range as Lahiri.

function kp_ayanamsa(year: float) → float

KP (Krishnamurti Paddhati) ayanamsa in degrees for a given decimal year. Nearly identical to Lahiri, using a slightly different J2000 reference value. Same valid range.

function fagan_bradley_ayanamsa(year: float) → float

Fagan-Bradley ayanamsa in degrees for a given decimal year. Standard ayanamsa of Western sidereal astrology. Linear model, valid ~1650-2150 (centered on 1950 reference).

function tropical_to_sidereal(tropical_longitude: float, ayanamsa: float) → float

Converts a tropical (Western) ecliptic longitude to sidereal (Vedic) longitude. sidereal = tropical - ayanamsa. Requires ayanamsa in [0, 30).

function sidereal_to_tropical(sidereal_longitude: float, ayanamsa: float) → float

Converts a sidereal (Vedic) ecliptic longitude to tropical (Western) longitude. tropical = sidereal + ayanamsa. Requires ayanamsa in [0, 30).

function centuries_since_j2000(jd: float) → float

Julian centuries elapsed since epoch J2000.0 (JD 2451545.0). The universal time variable T for all formulas below. Requires jd > 0 (positive Julian Day). Recommended valid range: JD 2305447.5-2488070.0 (1600-2200 CE).

function atan2_degrees(y: float, x: float) → float

Quadrant-aware arctangent (atan2 equivalent), returning degrees in [0, 360). Requires x and y not both zero (undefined angle).

function solve_kepler_equation(mean_anomaly_deg: float, eccentricity: float) → float

Solves Kepler's equation (M = E - e*sin(E)) for eccentric anomaly via Newton-Raphson iteration. mean_anomaly_deg in degrees, eccentricity as decimal in [0, 1). Returns eccentric anomaly in degrees. Uses 15 iterations with convergence check (tolerance 1E-10 rad). Errors if not converged.

function true_anomaly_from_eccentric(eccentric_anomaly_deg: float, eccentricity: float) → float

True anomaly from eccentric anomaly via the half-angle relation. eccentric_anomaly_deg in degrees, eccentricity as decimal in [0, 1).

function heliocentric_distance(semi_major_axis: float, eccentric_anomaly_deg: float, eccentricity: float) → float

Heliocentric distance in AU from semi-major axis, eccentric anomaly, and eccentricity. r = a(1 - e*cos(E)). Requires a > 0 and 0 <= e < 1.

function heliocentric_longitude(true_anomaly_deg: float, perihelion_longitude_deg: float) → float

Heliocentric ecliptic longitude from true anomaly and longitude of perihelion. Both in degrees. No constraints (pure angle addition + normalization).

function mean_longitude_at_time(l0: float, l_rate_per_century: float, t: float) → float

Mean longitude at time T from J2000 reference value and rate per Julian century. No constraints (pure linear extrapolation).

function mean_anomaly_from_elements(mean_longitude_deg: float, perihelion_longitude_deg: float) → float

Mean anomaly from mean longitude and longitude of perihelion. No constraints.

function earth_heliocentric_distance(sun_mean_anomaly_deg: float) → float

Earth's heliocentric distance in AU from the Sun's mean anomaly (Meeus simplified formula). Valid for realistic Sun mean anomaly values (any real input works, but model is only good for actual Earth orbit).

function geocentric_longitude_from_heliocentric(r_planet: float, l_planet_deg: float, r_earth: float, l_earth_deg: float) → float

Geocentric ecliptic longitude of a planet from both bodies' heliocentric distance/longitude (2D vector method, assumes coplanar orbits). r_planet and r_earth in AU (>0); longitudes in degrees. Errors if planet and Earth are at the same position (impossible — collision).

function pluto_ecliptic_longitude(t: float) → float

Pluto's geocentric ecliptic longitude at time T (tropical). CAVEAT: Pluto's eccentricity (0.249) and orbital inclination (~17°) are far higher than any other. body in this pipeline. The coplanar-with-ecliptic assumption used throughout this section is at its. weakest here — expect degree-level error, not the ~0.01-0.5° range typical of the other planets. Included for completeness (some modern astrological traditions use it), not for precision work.

Local Sidereal Time in degrees from Julian Day and observer's longitude (east positive, west negative). LST = GMST(JD) + longitude. Uses standard Meeus GMST formula. Requires jd > 0.

Midheaven (MC) ecliptic longitude — point where ecliptic crosses local meridian. lst_deg = local sidereal time in degrees, obliquity_deg in [20, 30).

Ascendant (Lagna) ecliptic longitude — point of ecliptic rising on eastern horizon. lst_deg = local sidereal time, latitude_deg in (-90, 90), obliquity_deg in [20, 30).

function placidus_intermediate_cusp(ramc_deg: float, latitude_deg: float, obliquity_deg: float, fraction: float, sign: float) → float

General Placidus intermediate cusp solver via semi-arc trisection (iterative fixed-point method). ramc_deg = right ascension of MC (= LST), latitude_deg in (-66, 66) for Placidus validity,. obliquity_deg in [20, 30), fraction in (0, 1), sign = -1.0 (Asc-MC quadrant) or +1.0 (MC-Desc quadrant). Errors if iteration does not converge in 25 steps.
