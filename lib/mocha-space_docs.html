function orbital_period(a: float, mu: float) → float

Kepler's 3rd law: orbital period in seconds from semi-major axis a (m) and mu (m³/s²). t = 2π √(a³/μ). Requires a > 0 and mu > 0.

function semi_major_axis(t: float, mu: float) → float

Semi-major axis in m from orbital period t (s) and mu (m³/s²). a = (μ(t/2π)²)^(1/3). Requires t > 0 and mu > 0.

function orbital_velocity_circular(r: float, mu: float) → float

Circular orbital velocity in m/s at radius r (m) with gravitational parameter mu (m³/s²). v = √(μ/r). Requires r > 0 and mu > 0.

function orbital_velocity_visviva(r: float, a: float, mu: float) → float

Orbital velocity in m/s at radius r (m) via vis-viva equation. v = √(μ(2/r - 1/a)). Requires r > 0, a > 0, and mu > 0. For hyperbolic orbits use a > 0 convention or pass negative a.

function escape_velocity(r: float, mu: float) → float

Escape velocity in m/s at radius r (m) with gravitational parameter mu (m³/s²). v = √(2μ/r). Requires r > 0 and mu > 0.

function periapsis(a: float, e: float) → float

Periapsis distance in m from semi-major axis a (m) and eccentricity e. r_p = a(1 - e). Requires a > 0 and 0 <= e < 1 (elliptical).

function apoapsis(a: float, e: float) → float

Apoapsis distance in m from semi-major axis a (m) and eccentricity e. r_a = a(1 + e). Requires a > 0 and 0 <= e < 1 (elliptical).

function orbital_energy(a: float, mu: float) → float

Specific orbital energy in J/kg from semi-major axis a (m) and mu (m³/s²). ε = -μ/(2a). Requires a non-zero and mu > 0.

function specific_angular_momentum(a: float, e: float, mu: float) → float

Specific angular momentum in m²/s from a (m), e, mu (m³/s²). h = √(μ·a·(1-e²)). Requires a > 0, 0 <= e <= 1 (elliptical/parabolic boundary).

function mean_motion(a: float, mu: float) → float

Mean motion in rad/s from semi-major axis a (m) and mu (m³/s²). n = √(μ/a³). Requires a > 0 and mu > 0.

function mean_anomaly(n: float, t: float, t_p: float) → float

Mean anomaly m (rad) at time t (s) given mean motion n (rad/s) and time of periapsis t_p (s). m = n(t - t_p).

function eccentric_anomaly(m: float, e: float) → float

Eccentric anomaly E (rad) from mean anomaly m (rad) and eccentricity e via Newton's method. Solves Kepler's equation m = E - e·sin(E). Converges to 1E-10 in ≤50 iterations for e < 1.

function true_anomaly_from_eccentric(E_cap: float, e: float) → float

True anomaly ν (rad) from eccentric anomaly E (rad) and eccentricity e. tan(ν/2) = √((1+e)/(1-e))·tan(E/2). Requires 0 <= e < 1.

function true_anomaly_from_mean(m: float, e: float) → float

True anomaly ν (rad) from mean anomaly m (rad) and eccentricity e. Combines Kepler solver + true anomaly conversion. Requires 0 <= e < 1.

function radial_distance(a: float, e: float, E_cap: float) → float

Radial distance in m at eccentric anomaly E (rad). r = a(1 - e·cos(E)). Requires a > 0 and 0 <= e < 1.

function flight_path_angle(e: float, nu: float) → float

Flight path angle γ (rad) from eccentricity e and true anomaly ν (rad). γ = atan2(e·sin(ν), 1 + e·cos(ν)). Requires e >= 0.

function synodic_period(p1: float, p2: float) → float

Synodic period in s between two orbital periods p1 (s) and p2 (s). 1/P_syn = |1/p1 - 1/p2|. Requires p1 > 0, p2 > 0, and p1 != p2.

function hohmann_transfer_sma(r1: float, r2: float) → float

Hohmann transfer ellipse semi-major axis in m from inner radius r1 (m) and outer radius r2 (m). a_t = (r1 + r2)/2. Requires r1 > 0 and r2 > 0.

function hohmann_dv1(r1: float, r2: float, mu: float) → float

Hohmann departure burn Δv in m/s from r1 (m), r2 (m), mu (m³/s²). Δv1 = √(μ/r1)·(√(2r2/(r1+r2)) - 1). Requires r1 > 0, r2 > 0, mu > 0.

function hohmann_dv2(r1: float, r2: float, mu: float) → float

Hohmann arrival burn Δv in m/s from r1 (m), r2 (m), mu (m³/s²). Δv2 = √(μ/r2)·(1 - √(2r1/(r1+r2))). Requires r1 > 0, r2 > 0, mu > 0.

function hohmann_dv_total(r1: float, r2: float, mu: float) → float

Total Hohmann transfer Δv magnitude in m/s (sum of departure and arrival burns). Requires r1 > 0, r2 > 0, mu > 0.

function sphere_of_influence(a: float, m_small: float, m_large: float) → float

Sphere of influence radius in m from semi-major axis a (m) and mass ratio. r_SOI = a·(m_small/m_large)^(2/5). Requires a > 0, m_small > 0, m_large > 0.

function hill_sphere(a: float, e: float, m_small: float, m_large: float) → float

Hill sphere radius in m from a (m), e, m_small (kg), m_large (kg). r_H = a(1-e)·(m_small/(3·m_large))^(1/3). Requires a > 0, 0 <= e < 1, masses > 0.

function roche_limit_rigid(R_primary: float, rho_primary: float, rho_secondary: float) → float

Roche limit in m for a rigid satellite from primary radius R (m) and densities (kg/m³). d = 2.46·R_primary·(ρ_primary/ρ_secondary)^(1/3). Requires R > 0 and both densities > 0.

function roche_limit_fluid(R_primary: float, M_primary: float, M_secondary: float) → float

Roche limit in m for a fluid satellite from primary radius R (m) and masses (kg). d = 2.44·R_primary·(M_primary/M_secondary)^(1/3). Requires R > 0 and both masses > 0.

function inclination_change_dv(v: float, delta_i_deg: float) → float

Δv in m/s for a pure inclination change from velocity v (m/s) and inclination change Δi (deg). Δv = 2v·sin(Δi/2). Requires v >= 0.

function orbit_type(e: float) → OrbitType

Classifies orbit by eccentricity e into OrbitType (CIRCULAR, ELLIPTICAL, PARABOLIC, HYPERBOLIC). Requires e >= 0.

function luminosity_from_radius_temp(r: float, t: float) → float

Stefan-Boltzmann law: stellar luminosity in W from radius r (m) and effective temperature t (K). L = 4π R² σ T⁴. Requires r > 0 and t > 0.

function radius_from_luminosity_temp(l: float, t: float) → float

Stellar radius in m from luminosity l (W) and effective temperature t (K). R = √(L / (4π σ T⁴)). Requires l > 0 and t > 0.

function temp_from_luminosity_radius(l: float, r: float) → float

Effective temperature in K from luminosity l (W) and radius r (m). T = (L / (4π R² σ))^(1/4). Requires l > 0 and r > 0.

function wien_peak_wavelength(t: float) → float

Wien's displacement law: peak emission wavelength in m from temperature t (K). λ_max = b / T. Requires t > 0.

function wien_temp_from_wavelength(lambda_max: float) → float

Inverse Wien's law: temperature in K from peak wavelength lambda_max (m). T = b / λ_max. Requires lambda_max > 0.

function parallax_to_distance_pc(p_arcsec: float) → float

Stellar distance in parsecs from parallax angle p_arcsec (arcsec). d = 1 / p″. Requires p_arcsec > 0.

function distance_modulus(m: float, M_abs: float) → float

Distance modulus in magnitudes from apparent magnitude m and absolute magnitude M_abs. μ = m - M. No constraint on magnitudes (negative values valid for bright objects).

function absolute_magnitude(m: float, d_pc: float) → float

Absolute magnitude from apparent magnitude m and distance d_pc (parsecs). M = m - 5·log10(d) + 5. Requires d_pc > 0.

function apparent_magnitude(M_abs: float, d_pc: float) → float

Apparent magnitude from absolute magnitude M_abs and distance d_pc (parsecs). m = M + 5·log10(d) - 5. Requires d_pc > 0.

function flux_ratio_from_magnitudes(m1: float, m2: float) → float

Flux ratio F1/F2 from two magnitudes m1 and m2. F1/F2 = 10^(0.4·(m2-m1)). No constraint (any real magnitudes valid).

function magnitude_diff_from_flux_ratio(ratio: float) → float

Magnitude difference Δm from flux ratio F1/F2. Δm = -2.5·log10(F1/F2). Requires ratio > 0.

Mass-luminosity relation for main sequence stars: L/L_sun ≈ (M/M_sun)^3.5. Valid roughly 0.5–20 solar masses. Requires mass_solar > 0.

function main_sequence_lifetime(mass_solar: float) → float

Approximate main sequence lifetime in years from stellar mass in solar units. t ≈ 10^10 · (M/M_sun) / (L/L_sun). Requires mass_solar > 0.

Event horizon radius in m for a non-rotating mass (Schwarzschild radius). r_s = 2GM/c². Requires mass > 0.

function equilibrium_temp(l: float, d: float, albedo: float) → float

Planetary equilibrium temperature in K from stellar luminosity l (W), orbital distance d (m), and Bond albedo. T_eq = (L(1-A) / (16π σ D²))^(1/4). Requires l > 0, d > 0, and 0 <= albedo < 1.

function equilibrium_temp_from_star(t_star: float, r_star: float, d: float, albedo: float) → float

Planetary equilibrium temperature in K from stellar temperature t_star (K), stellar radius r_star (m), orbital distance d (m), and Bond albedo. T_eq = T_star · √(R_star / (2D)) · (1-A)^(1/4). Requires t_star > 0, r_star > 0, d > 0, and 0 <= albedo < 1.

Atmospheric scale height in m from temperature t (K), molar mass (kg/mol), and surface gravity g (m/s²). H = RT / (Mg). Requires t > 0, molar_mass > 0, and g > 0.

Simplified Earth-equivalent-insolation habitable zone distance in AU from stellar luminosity l_solar (solar units). d_HZ = √(L / L_sun). First-pass estimate — for the full Kasting et al. (1993) model, use the temperature-dependent version. Requires l_solar > 0.

function mean_free_path(temp: float, pressure: float, molecule_diameter: float) → float

Mean free path of gas molecules in m from temperature temp (K), pressure (Pa), and molecule diameter (m). λ = kT / (√2 · π · d² · P). Requires temp > 0, pressure > 0, and molecule_diameter > 0.

function jeans_escape_parameter(escape_v: float, thermal_v: float) → float

Jeans escape parameter λ_J — ratio governing atmospheric retention. Values >> 1 indicate the gas is gravitationally bound (retained); values << 1 indicate rapid thermal escape. λ_J = (v_esc / v_thermal)². Requires escape_v >= 0 and thermal_v > 0.

function thermal_velocity(temp: float, molar_mass: float) → float

Most probable thermal speed of gas molecules in m/s from temperature (K) and molar mass (kg/mol). v_thermal = √(2RT/M) (Maxwell-Boltzmann most probable speed). Requires temp > 0 and molar_mass > 0.
