function wren_open() → null native

Mocha-Wren FFI Library. Provides bidirectional Wren integration for Mocha programs. Use wren_open() to create a Wren VM and wren_close() to destroy it. Wren is class-based — most call functions require a module and class name. Creates a new Wren VM. Returns an opaque handle.
