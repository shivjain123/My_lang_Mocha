function sqlite3_open(path: str) → null native

Mocha-SQLite3 Library. Provides SQLite3 database access for Mocha programs. Use sqlite3_open() to open a database and sqlite3_close() when done. Note: SQL strings are passed directly — sanitize user input to avoid injection. Opens a SQLite3 database file. Creates it if it does not exist.

parameterdescription
pathfile path to the .db file
