function population_growth_rate(p0: float, p1: float, years: float) → float

Continuous (exponential) annual population growth rate from initial and final population. p0, p1 = population counts (both > 0), years = elapsed time (must be > 0). r = ln(P1/P0) / years.

function population_doubling_time(growth_rate: float) → float

Population doubling time in years from a continuous growth rate. growth_rate as a decimal in (0, 1] (e.g. 0.02 = 2% per year). t = ln(2) / r. For negative growth (population decline), use halving-time reasoning explicitly — not this function.

function crude_birth_rate(births: float, population: float) → float

Crude birth rate per 1000 population. births = number of live births (>= 0), population = total population (> 0).

function crude_death_rate(deaths: float, population: float) → float

Crude death rate per 1000 population. deaths = number of deaths (>= 0), population = total population (> 0).

function natural_increase_rate(cbr: float, cdr: float) → float

Rate of natural increase as a percentage, from crude birth and death rates. cbr, cdr = crude birth/death rate (per 1000, both >= 0). NIR(%) = (CBR - CDR) / 10.

function net_migration_rate(immigrants: float, emigrants: float, population: float) → float

Net migration rate per 1000 population. immigrants, emigrants = counts over the period (both >= 0), population = total population (> 0).

function dependency_ratio(pop_under15: float, pop_65plus: float, pop_working: float) → float

Total age dependency ratio (per 100 working-age population). pop_under15, pop_65plus = dependent age groups (both >= 0), pop_working = population aged 15-64 (> 0).

function child_dependency_ratio(pop_under15: float, pop_working: float) → float

Child dependency ratio (per 100 working-age population). pop_under15 >= 0, pop_working > 0.

function old_age_dependency_ratio(pop_65plus: float, pop_working: float) → float

Old-age dependency ratio (per 100 working-age population). pop_65plus >= 0, pop_working > 0.

function population_projection(p0: float, growth_rate: float, years: float) → float

Projects future population using continuous exponential growth. p0 = initial population (> 0), growth_rate as decimal, years = projection horizon. P(t) = P0 * e^(r*t). Errors if |r*years| > 700 (e^700 overflows double precision).

function mean_income(incomes: float[]) → float

Arithmetic mean of an income/wealth distribution. incomes = array of values (any consistent unit). Requires non-empty array.

function gini_coefficient(incomes: float[]) → float

Gini coefficient of income inequality (0 = perfect equality, 1 = perfect inequality). incomes MUST be sorted ascending and must all be >= 0. Requires non-empty array and positive total. Uses rank-sum formula: G = (2*Σ(rank_i * x_i) - (n+1)*Σx_i) / (n*Σx_i).

function theil_index(incomes: float[]) → float

Theil index of inequality (0 = perfect equality, higher = more unequal, unbounded above). incomes = array of values in any order, all must be > 0. T = (1/n) * Σ( (x_i/mean) * ln(x_i/mean) ).

function atkinson_index(incomes: float[], epsilon: float) → float

Atkinson index of inequality, sensitive to a chosen inequality-aversion parameter. incomes = array of values (non-empty), epsilon = inequality aversion (> 0 and != 1). Higher epsilon weights the bottom of the distribution more. A = 1 - (1/mean) * [(1/n)*Σx_i^(1-ε)]^(1/(1-ε)).

function poverty_headcount_ratio(poor_count: float, total_population: float) → float

Poverty headcount ratio as a percentage of total population. poor_count in [0, total_population], total_population > 0.

function poverty_gap_index(incomes: float[], poverty_line: float) → float

Poverty gap index — average normalized income shortfall below the poverty line across whole population. incomes = array of values (including those above the line), poverty_line > 0. Requires non-empty array. PGI = (1/n) * Σ max(0, (z - x_i)/z).

function palma_ratio(top10_share: float, bottom40_share: float) → float

Palma ratio: income share of the top 10% divided by the income share of the bottom 40%. top10_share and bottom40_share as percentages, both > 0.

function income_share_ratio(top_share: float, bottom_share: float) → float

General income share ratio between any two population deciles/quintiles. top_share and bottom_share as percentages, both > 0.

function relative_poverty_line(median_income: float, threshold_fraction: float) → float

Relative poverty line as a fraction of median income (commonly 0.5 or 0.6, OECD/EU convention). median_income > 0, threshold_fraction in (0, 1].

function voter_turnout_rate(votes_cast: float, eligible_voters: float) → float

Voter turnout rate as a percentage. votes_cast in [0, eligible_voters], eligible_voters > 0.

function dhondt_apportionment(votes: float[], total_seats: int) → int[]

Seat allocation via D'Hondt highest-averages method. votes = non-empty array of non-negative party vote totals, total_seats >= 0. Returns array of seats per party (same order as input). Divisor sequence: 1,2,3,.

function sainte_lague_apportionment(votes: float[], total_seats: int) → int[]

Seat allocation via Sainte-Laguë highest-averages method. votes = non-empty array of non-negative party vote totals, total_seats >= 0. Returns array of seats per party (same order). Divisor sequence: 1,3,5,7,.

function effective_number_of_parties(vote_shares: float[]) → float

Effective number of parties (Laakso-Taagepera index). vote_shares = non-empty array of fractional shares in [0, 1] summing to ~1.0. ENP = 1 / Σ(share_i²).

function gallagher_index(vote_shares: float[], seat_shares: float[]) → float

Gallagher least-squares disproportionality index. vote_shares and seat_shares as percentages (same length, both non-empty). G = sqrt(0.5 * Σ(v_i - s_i)²).

function seat_vote_deviation(vote_share: float, seat_share: float) → float

Per-party deviation between vote share and seat share (a single Gallagher term). vote_share and seat_share as percentages. Returns vote_share - seat_share.

function banzhaf_power_index_3player(w1: float, w2: float, w3: float, quota: float) → (float, 3)

Banzhaf power index for 3-player weighted voting game. w1, w2, w3 = non-negative voting weights, quota = votes needed to win (> 0 and <= w1+w2+w3). Returns (power1, power2, power3) — fraction of winning coalitions where each player is critical.

function shapley_shubik_power_index_3player(w1: float, w2: float, w3: float, quota: float) → (float, 3)

Shapley-Shubik power index for 3-player weighted voting game. w1, w2, w3 = non-negative voting weights, quota = votes needed to win (> 0 and <= w1+w2+w3). Returns (power1, power2, power3) — fraction of 6 orderings where each player is pivotal.

function validate_adjacency(adjacency: int[][]) → int

Validates an adjacency matrix: non-empty, square, symmetric, 0/1 entries only. Returns node count (n). Called by all functions in this section.

function validate_node_index(node_index: int, n: int) → int

Validates node_index is within bounds.

function node_degree(adjacency: int[][], node_index: int) → int

Degree of a node — number of edges connected to it. adjacency = n×n symmetric adjacency matrix, node_index in [0, n-1].

function degree_centrality(adjacency: int[][], node_index: int) → float

Degree centrality — node's degree normalized by maximum possible degree (n-1). Requires n >= 2 (undefined for single-node graph).

function network_density(adjacency: int[][]) → float

Network density — fraction of possible edges that exist. D = 2E / (n(n-1)). Requires n >= 2.

function average_degree(adjacency: int[][]) → float

Average node degree across the whole network. Requires n >= 1.

function clustering_coefficient(adjacency: int[][], node_index: int) → float

Local clustering coefficient — how interconnected a node's neighbors are with each other. C(v) = 2*E_v / (k_v*(k_v-1)). Returns 0.0 for nodes with degree < 2.

function shortest_path_length(adjacency: int[][], source: int, target: int) → int

Shortest path length (in edges) via BFS. Returns -1 if source and target are not connected. source, target in [0, n-1].

function closeness_centrality(adjacency: int[][], node_index: int) → float

Closeness centrality — how close a node is to all others. Requires connected graph (n >= 2). C(v) = (n-1) / Σ(shortest_path_length(v, i)). Errors if any node is unreachable.

function betweenness_centrality(adjacency: int[][], node_index: int) → float

Betweenness centrality (raw/unnormalized) — how often a node lies on shortest paths. Requires connected graph (for correctness of intermediate path check).

function homophily_index(adjacency: int[][], attributes: int[]) → float

Homophily index — fraction of edges connecting nodes with same attribute. attributes array must match adjacency length.

function coefficient_of_relationship(num_paths: int, links_per_path: int) → float

Wright's coefficient of relationship (r), via path-counting through shared ancestors. num_paths >= 1, links_per_path >= 1 (at least one generation link). Result in [0, 1]. r = num_paths * (0.5)^links_per_path.

function inbreeding_coefficient(parental_relationship: float) → float

Inbreeding coefficient of offspring from parents with a given coefficient of relationship. parental_relationship in [0, 1] (assumes parents themselves non-inbred). F = r / 2.

function simpsons_diversity_index(counts: float[]) → float

Simpson's Diversity Index — probability that two randomly sampled individuals belong to different groups. counts = non-empty array of non-negative group population sizes with positive total. D = 1 - Σ(p_i²).

function simpsons_reciprocal_index(counts: float[]) → float

Simpson's Reciprocal Index — effective number of equally-common groups. counts = non-empty array of non-negative group sizes with positive total. 1/D = 1 / Σ(p_i²).

function shannon_diversity_index(counts: float[]) → float

Shannon Diversity Index (entropy-based). H = -Σ(p_i * ln(p_i)). Zero-count groups contribute 0 (limit convention). counts = non-empty array of non-negative group sizes with positive total.

function shannon_evenness_index(counts: float[]) → float

Shannon Evenness Index — E = H / ln(S). Returns 1.0 if only one group (perfectly even by convention). Requires non-empty counts with positive total.

function cultural_distance_index(differing_traits: int, total_traits: int) → float

Cultural distance index — proportion of cultural traits that differ between two groups. differing_traits in [0, total_traits], total_traits > 0.

function cultural_similarity_index(differing_traits: int, total_traits: int) → float

Cultural similarity index — complement of cultural distance. differing_traits in [0, total_traits], total_traits > 0.

Validates a proportion is in [0, 1].

Validates a value is positive.

function validate_non_negative(x: float, name: str) → float

Validates a value is non-negative.

function cronbachs_alpha(item_variances: float[], total_variance: float) → float

Cronbach's alpha — internal consistency reliability. Requires k >= 2 items and positive total variance. α = (k/(k-1)) * (1 - Σ(item_variances)/total_variance).

function cohens_kappa(observed_agreement: float, expected_agreement: float) → float

Cohen's kappa — inter-rater reliability. Requires both proportions in [0, 1] and expected < 1.0. κ = (p_o - p_e) / (1 - p_e).

function standard_error_of_proportion(p: float, n: float) → float

Standard error of a sample proportion. p in [0, 1], n > 0. SE = sqrt(p*(1-p)/n).

function margin_of_error_proportion(p: float, n: float, z_score: float) → float

Margin of error for a sample proportion. z_score > 0. MOE = z * SE(p).

function sample_size_for_proportion(z_score: float, p: float, margin_of_error: float) → float

Required sample size to estimate a proportion within a target margin of error. z_score > 0, p in [0, 1], margin_of_error > 0. n = (z² * p*(1-p)) / E².

function confidence_interval_proportion(p: float, n: float, z_score: float) → (float, 2)

Confidence interval for a sample proportion. Returns (lower, upper), clamped to [0, 1]. Note: this is the Wald interval, which can be inaccurate for extreme proportions near 0 or 1. For proportions near 0/1 or small n, use the Wilson score interval instead.

function standard_error_of_mean(std_dev: float, n: float) → float

Standard error of the mean. std_dev >= 0, n > 0. SEM = std_dev / sqrt(n).

function pooled_standard_deviation(std1: float, n1: float, std2: float, n2: float) → float

Pooled standard deviation across two independent samples. n1 >= 2, n2 >= 2.

function cohens_d(mean1: float, mean2: float, pooled_std: float) → float

Cohen's d — standardized effect size. pooled_std > 0.

function pearson_correlation_coefficient(x: float[], y: float[]) → float

Pearson correlation coefficient. x and y must be same length, both non-empty with positive variance. r = Σ((x-x̄)(y-ȳ)) / sqrt(Σ(x-x̄)² * Σ(y-ȳ)²).

function life_expectancy_index(life_expectancy: float, min_val: float, max_val: float) → float

Life expectancy sub-index for HDI (UNDP min-max normalization). Result in [0, 1]. Requires max_val > min_val, life_expectancy >= 0.

function schooling_index(years: float, min_years: float, max_years: float) → float

Schooling sub-index for HDI (general purpose). Result in [0, 1]. Requires max_years > min_years, years >= 0.

function education_index(mean_years_index: float, expected_years_index: float) → float

Education sub-index for HDI, averaging mean-years and expected-years indices. Both inputs must be in [0, 1].

function income_index(gni_per_capita: float, min_gni: float, max_gni: float) → float

Income sub-index for HDI (UNDP log-scale normalization). Result in [0, 1]. Requires gni_per_capita > 0, min_gni > 0, max_gni > min_gni.

function human_development_index(life_exp_idx: float, edu_idx: float, inc_idx: float) → float

Human Development Index — geometric mean of three sub-indices. Result in [0, 1]. All inputs must be in [0, 1].

function gdp_per_capita_growth_rate(gdp0: float, gdp1: float, years: float) → float

Continuous annual GDP per capita growth rate. gdp0 > 0, gdp1 > 0, years > 0. r = ln(GDP1/GDP0) / years.

function income_elasticity_of_demand(percent_change_quantity: float, percent_change_income: float) → float

Income elasticity of demand. percent_change_income != 0. Elasticity > 1 = luxury, < 1 = necessity, < 0 = inferior good.

function engels_coefficient(food_expenditure: float, total_expenditure: float) → float

Engel's coefficient — share of household expenditure on food. Result in [0, 100]. food_expenditure in [0, total_expenditure], total_expenditure > 0.

function unemployment_rate(unemployed: float, labor_force: float) → float

Unemployment rate as percentage of labor force. unemployed in [0, labor_force], labor_force > 0.

function labor_force_participation_rate(labor_force: float, working_age_population: float) → float

Labor force participation rate as percentage of working-age population. labor_force >= 0, working_age_population > 0.

function purchasing_power_parity_adjustment(nominal_value: float, ppp_conversion_factor: float) → float

Converts nominal monetary value to PPP-adjusted real value. nominal_value >= 0, ppp_conversion_factor > 0.

function misery_index(inflation_rate: float, unemployment_rate_val: float) → float

Misery index — sum of inflation and unemployment rates. Either input may be negative (deflation is meaningful). No range constraint.
