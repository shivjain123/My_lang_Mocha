function richter_magnitude(amplitude_mm: float, distance_km: float) → float

Computes Richter local magnitude (ML) from peak Wood-Anderson amplitude. and epicentral distance. amplitude_mm in mm, distance_km in km.

function moment_magnitude(m0: float) → float

Computes moment magnitude (Mw) from scalar seismic moment M0 in N·m. Uses Hanks & Kanamori (1979): Mw = (2/3)*log10(M0) - 6.07.

function seismic_moment(rigidity: float, area: float, slip: float) → float

Computes scalar seismic moment M0 = μ * A * D in N·m. rigidity in Pa, area in m², slip in m. Uses unsafe_mul: real fault products far exceed fixed-point range.

function energy_release(mw: float) → float

Radiated seismic energy in joules from moment magnitude. Gutenberg-Richter energy relation: E = 10^(1.5*Mw + 4.8). Keep test values Mw <= 6.0 to stay within fixed-point range.

function p_wave_travel_time(distance_km: float, vp: float) → float

P-wave travel time in seconds from epicentral distance and P-wave velocity. distance_km in km, vp in km/s (typical crustal range: 5.5-8.0).

function s_wave_travel_time(distance_km: float, vs: float) → float

S-wave travel time in seconds from epicentral distance and S-wave velocity. distance_km in km, vs in km/s (typical crustal range: 3.0-5.0).

function sp_time_interval_distance(sp_interval: float, vp: float, vs: float) → float

Estimates epicentral distance in km from S-P arrival time interval. Wadati method: distance = (vp*vs)/(vp-vs) * (ts-tp).

function epicenter_triangulation(d1: float, d2: float, d3: float, lat1: float, lon1: float, lat2: float, lon2: float, lat3: float, lon3: float) → (float, 2)

Estimates epicenter lat/lon from three station distances via flat-Earth trilateration. d1/d2/d3 in km. lat/lon in degrees. Valid for distances < 500 km. Returns (lat, lon) tuple.

function peak_ground_acceleration(mw: float, distance_km: float) → float

Peak ground acceleration in g from moment magnitude and distance. Joyner-Boore (1981) simplified attenuation relation. Valid range: Mw 5.0-7.5, distance 10-100 km.

function mercalli_intensity_estimate(pga_g: float) → float

Estimates Modified Mercalli Intensity (MMI) from peak ground acceleration in g. Wald et al. (1999). Returns continuous value; round to nearest 0.5 for reporting.

function specific_gravity(density_kg_m3: float) → float

Specific gravity of a mineral as ratio of its density to water (1000 kg/m³). Input density in kg/m³. Returns dimensionless SG value.

function unit_cell_volume(a: float, b: float, c: float, alpha: float, beta: float, gamma: float) → float

Unit cell volume in Å³ from lattice parameters using general triclinic formula. a, b, c in Angstroms; alpha, beta, gamma in degrees. Covers all 7 crystal systems.

function theoretical_density(formula_mass: float, z: float, cell_volume: float) → float

Theoretical density in g/cm³ from unit cell parameters. formula_mass in g/mol, z = atoms per unit cell, cell_volume in Å³. Uses 1.6605 conversion factor (1e24 / Avogadro).

function bragg_angle(wavelength: float, d_spacing: float, n: int) → float

Bragg diffraction angle θ in degrees from wavelength, d-spacing, and reflection order n. wavelength and d_spacing in Angstroms. Note: diffractometers report 2θ, so double if needed.

function d_spacing_cubic(a: float, h: int, k: int, l: int) → float

d-spacing in Angstroms for cubic crystal system from Miller indices (hkl). d = a / sqrt(h² + k² + l²). a in Angstroms.

function d_spacing_hexagonal(a: float, c: float, h: int, k: int, l: int) → float

d-spacing in Angstroms for hexagonal crystal system from Miller indices (hkl). Covers quartz, calcite, apatite and most rock-forming hexagonal minerals.

function mohs_to_vickers_estimate(mohs: float) → float

Estimates Vickers hardness (HV) from Mohs hardness scale value. Tabor empirical approximation: HV ≈ 10^(0.6 * Mohs). Rough ±50%.

function packing_efficiency(structure: CrystalStructure) → float

Atomic packing efficiency for ideal hard-sphere model by crystal structure. FCC/HCP: 0.7405 | BCC: 0.6802 | SC: 0.5236.

function coordination_number_estimate(radius_cation: float, radius_anion: float) → int

Predicted coordination number from Pauling radius ratio rule. radius_cation and radius_anion in same units (typically Angstroms).

function madelung_constant_estimate(coordination_number: int) → float

Madelung constant for common ionic crystal structures, looked up by coordination number. CN 4: zinc blende (1.6381) | CN 6: NaCl rock salt (1.7476) | CN 8: CsCl (1.7627).

function plate_velocity(displacement_km: float, time_myr: float) → float

Plate velocity in cm/yr from displacement in km and time in Myr. Conversion: 1 km/Myr = 0.1 cm/yr.

function euler_pole_velocity(angular_velocity_deg_myr: float, angular_distance_deg: float) → float

Linear plate velocity in cm/yr from Euler pole angular velocity and angular distance. angular_velocity in deg/Myr, angular_distance in degrees (angle from Euler pole). v = ω * R * sin(δ), using Earth radius R = 6371 km.

function relative_plate_motion(vx1: float, vy1: float, vx2: float, vy2: float) → (float, 2)

Relative plate motion vector from two absolute plate velocity vectors (cm/yr). Returns (rel_vx, rel_vy) = (v1 - v2) as a tuple.

function normal_stress(sigma1: float, sigma3: float, theta_deg: float) → float

Normal stress on a plane oriented at angle theta from sigma1, using 2D Mohr circle relation. sigma1, sigma3 in MPa (or consistent units), theta in degrees.

function shear_stress(sigma1: float, sigma3: float, theta_deg: float) → float

Shear stress on a plane oriented at angle theta, using 2D Mohr circle relation. sigma1, sigma3 in MPa (or consistent units), theta in degrees.

function true_dip(apparent_dip_deg: float, alpha_deg: float) → float

True dip in degrees from apparent dip and the angle between the vertical cross-section and true dip direction. tan(true_dip) = tan(apparent_dip) / cos(alpha).

function strike_from_dip_direction(dip_direction_deg: float) → float

Strike in degrees from dip direction, using the rule strike = dip_direction - 90°. Wraps result into [0, 360) range.

function airy_isostasy_root(elevation_km: float, crust_density: float, mantle_density: float) → float

Crustal root depth in km via Airy isostasy from topographic elevation and density contrast. elevation_km in km, crust_density and mantle_density in kg/m³. r = h * ρc / (ρm - ρc).

function fault_heave_throw(slip: float, dip_deg: float) → (float, 2)

Fault heave and throw from slip vector magnitude and dip angle. slip in any length unit, dip_deg in degrees. Returns (heave, throw) tuple.

function strain_ellipse_ratio(e1: float, e3: float) → float

Strain ellipse axial ratio Rs from principal extensions e1 (max) and e3 (min). Rs = (1 + e1) / (1 + e3). e1, e3 as decimal extension values (e.g. 0.3 = 30%).

function hydraulic_gradient(h1: float, h2: float, distance: float) → float

Hydraulic gradient (dimensionless) between two points in an aquifer. h1, h2 = hydraulic head at points 1 and 2 (same length units), L = distance between them.

function darcy_flux(k: float, i: float) → float

Darcy flux (specific discharge) in m/s from hydraulic conductivity and gradient. K = hydraulic conductivity (m/s), i = hydraulic gradient (dimensionless).

function darcy_discharge(k: float, area: float, i: float) → float

Darcy volumetric discharge in m³/s through a cross-sectional area. K in m/s, area in m², i = hydraulic gradient.

function transmissivity(k: float, thickness: float) → float

Aquifer transmissivity in m²/s from hydraulic conductivity and saturated thickness. K in m/s, thickness in m.

function seepage_velocity(darcy_flux_val: float, porosity: float) → float

Seepage (linear) velocity in m/s, the actual average velocity of water through pore spaces. darcy_flux in m/s, porosity as decimal fraction (e.g. 0.3 = 30%).

function porosity(void_volume: float, total_volume: float) → float

Porosity as a decimal fraction from void volume and total volume. Same units for both volumes.

function manning_velocity(manning_n: float, hydraulic_radius: float, slope: float) → float

Open-channel flow velocity in m/s via Manning's equation. manning_n = roughness coefficient (dimensionless), hydraulic_radius in m, slope as decimal.

function stream_discharge(area: float, velocity: float) → float

Stream discharge in m³/s from channel cross-sectional area and average velocity. area in m², velocity in m/s.

function reynolds_number_pipe(velocity: float, diameter: float, kinematic_viscosity: float) → float

Reynolds number for pipe flow (dimensionless), determines laminar vs turbulent regime. velocity in m/s, diameter in m, kinematic_viscosity in m²/s (water ≈ 1.0e-6).

function cooper_jacob_drawdown(q: float, t_aquifer: float, time_s: float, r: float, storativity: float) → float

Cooper-Jacob approximation for aquifer drawdown at distance r and time t (confined aquifer, pumping test). Q in m³/s, T = transmissivity in m²/s, t in seconds, r in m, S = storativity (dimensionless). Valid for large t / small r (u < 0.01).

function time_of_travel(path_length: float, seepage_velocity_val: float) → float

Groundwater time of travel in seconds over a flow path length using seepage velocity. path_length in m, seepage_velocity in m/s.

function volcanic_explosivity_index_estimate(volume_km3: float) → int

Estimates Volcanic Explosivity Index (0-8) from erupted tephra volume. volume_km3 in cubic kilometers. Coarse approximation from Newhall & Self (1982) volume boundaries. VEI = floor(log10(V_m3)) - 3, clamped to [0, 8].

function eruption_column_height(mass_rate_kgs: float) → float

Eruption column height in km from mass eruption rate, via the Sparks et al. scaling law. mass_rate_kgs in kg/s. H = 0.236 * Q^0.25.

function mass_eruption_rate(height_km: float) → float

Mass eruption rate in kg/s from eruption column height (inverse Sparks scaling). height_km in km. Q = (H/0.236)^4.

function magma_ascent_velocity(pressure_gradient: float, radius: float, viscosity: float, conduit_length: float) → float

Magma ascent velocity in m/s through a cylindrical conduit via Hagen-Poiseuille flow. pressure_gradient in Pa, radius in m, viscosity in Pa·s, conduit_length in m. v = ΔP·r² / (8·η·L).

function effusion_rate(volume_km3: float, duration_days: float) → float

Effusion rate in m³/s from erupted lava volume and eruption duration. volume_km3 in cubic kilometers, duration_days in days.

function lava_volume_from_effusion(effusion_rate_m3s: float, duration_s: float) → float

Total lava volume in m³ from effusion rate and eruption duration. effusion_rate_m3s in m³/s, duration_s in seconds.

function magma_viscosity_suspension(melt_viscosity: float, crystal_fraction: float, max_packing_fraction: float) → float

Crystal-bearing magma suspension viscosity via the Einstein-Roscoe equation. melt_viscosity in Pa·s, crystal_fraction and max_packing_fraction as decimals (0-1). η_suspension = η_melt * (1 - φ/φmax)^(-2.5·φmax).

function magma_chamber_overpressure(tensile_strength: float, rock_density: float, magma_density: float, depth: float) → float

Critical overpressure in Pa needed for dike initiation from a magma chamber (Gudmundsson model). tensile_strength in Pa, rock_density and magma_density in kg/m³, depth in m. ΔPc = σt + (ρrock - ρmagma)·g·depth.

function tephra_fallout_thickness(t0: float, decay_constant: float, distance_km: float) → float

Tephra deposit thickness in cm at a given distance from vent, via the Pyle (1989) exponential thinning model. t0 = thickness at vent (cm), decay_constant per km, distance_km from vent.

function silica_classification_index(sio2_wt_pct: float) → RockType

Classifies volcanic rock type from silica content using standard TAS-adjacent thresholds. sio2_wt_pct in weight percent. Basalt <52%, Andesite 52-63%, Dacite 63-70%, Rhyolite >70%.

function decay_constant_myr(half_life_myr: float) → float

Decay constant in Myr⁻¹ from half-life in Myr. λ = ln(2)/t_half.

function parent_daughter_age(lambda_myr: float, daughter_excess: float, parent_remaining: float) → float

General radiometric age in Myr from decay constant and parent/daughter isotope amounts. lambda in Myr⁻¹, daughter_excess and parent_remaining in same units (e.g. mol, or isotope ratio). age = (1/λ) * ln(1 + D/P).

function u238_pb206_age(pb206_excess: float, u238_remaining: float) → float

U-238/Pb-206 radiometric age in Myr. Half-life = 4468 Myr. pb206_excess and u238_remaining in same units (e.g. mol or isotope ratio).

function u235_pb207_age(pb207_excess: float, u235_remaining: float) → float

U-235/Pb-207 radiometric age in Myr. Half-life = 703.8 Myr. pb207_excess and u235_remaining in same units.

function rb87_sr87_age(sr87_excess: float, rb87_remaining: float) → float

Rb-87/Sr-87 radiometric age in Myr. Half-life = 48800 Myr. sr87_excess and rb87_remaining in same units.

function sm147_nd143_age(nd143_excess: float, sm147_remaining: float) → float

Sm-147/Nd-143 radiometric age in Myr. Half-life = 106000 Myr. nd143_excess and sm147_remaining in same units.

function k40_ar40_age(ar40_excess: float, k40_remaining: float) → float

K-40/Ar-40 radiometric age in Myr, accounting for the electron-capture branching ratio. ar40_excess and k40_remaining in same units. Uses Steiger & Jäger (1977) constants:. λtotal = 5.543e-4/Myr, λε = 0.581e-4/Myr.

function deposition_rate(thickness_m: float, time_kyr: float) → float

Sediment deposition rate in m/kyr from layer thickness and time elapsed. thickness_m in meters, time_kyr in thousands of years.

function sediment_age_from_depth(depth_m: float, rate: float) → float

Sediment age in kyr from burial depth and deposition rate. depth_m in meters, rate in m/kyr.

function luminescence_age(paleodose_gy: float, dose_rate: float) → float

Luminescence (OSL/TL) age in kyr from paleodose and environmental dose rate. paleodose_gy in Gray (Gy), dose_rate in Gy/kyr.
