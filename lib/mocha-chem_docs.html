function van_der_waals_pressure(n: float, t_k: float, v_l: float, a: float, b: float) → float

van_der_waals_pressure: pressure of a real gas (atm). Uses R = 0.082057 L·atm/(mol·K). n > 0, t_k > 0, v_l > n*b (volume must exceed excluded volume), a > 0, b > 0. P = nRT/(V - nb) - a(n/V)^2.

van_der_waals_molar_volume: molar volume (L/mol) of a real gas, via Newton-Raphson. p > 0, t_k > 0, a > 0, b > 0. Valid for gas-phase conditions (above critical temperature). Errors if Newton-Raphson fails to converge in 50 iterations.

function keq_from_gibbs(delta_g_std: float, t_k: float) → float

keq_from_gibbs: equilibrium constant from standard Gibbs free energy. Requires t_k > 0. K = exp(-delta_g_std / RT).

function clausius_clapeyron_p2(p1: float, t1_k: float, t2_k: float, delta_h_vap: float) → float

clausius_clapeyron_p2: vapour pressure at t2_k given known p1 at t1_k (same units as p1). Requires p1 > 0, t1_k > 0, t2_k > 0, delta_h_vap > 0. ln(P2/P1) = -(delta_h_vap/R) * (1/T2 - 1/T1).

function clausius_clapeyron_t2(p1: float, p2: float, t1_k: float, delta_h_vap: float) → float

clausius_clapeyron_t2: temperature at p2 given known p1 at t1_k (K). Requires p1 > 0, p2 > 0, t1_k > 0, delta_h_vap > 0. Errors if T2 solution is non-physical. 1/T2 = 1/T1 - (R/delta_h_vap) * ln(P2/P1).

function bond_enthalpy_rxn(bonds_broken: float, bonds_formed: float) → float

bond_enthalpy_rxn: enthalpy of reaction from bond energies (kJ/mol). No constraints. delta_h = bonds_broken - bonds_formed.

function kirchhoff_enthalpy(delta_h_t1: float, delta_cp: float, t1_k: float, t2_k: float) → float

kirchhoff_enthalpy: enthalpy at t2_k corrected for heat capacity (J/mol). Requires t1_k > 0 and t2_k > 0 (both absolute temperatures). delta_h(T2) = delta_h(T1) + delta_cp * (T2 - T1).

function entropy_surroundings(delta_h_sys: float, t_k: float) → float

function gibbs_equilibrium_temp(delta_h: float, delta_s: float) → float

gibbs_equilibrium_temp: temperature at which delta_g = 0 (K). T = delta_h / delta_s. Errors if delta_s = 0 (division by zero). NOTE: if delta_h and delta_s have opposite signs, the equation has NO positive-temperature solution — errors with explanation.

function conc_zero_order(conc_init: float, k: float, t: float) → float

conc_zero_order: concentration at time t for zero-order reaction (mol/L). Requires conc_init >= 0, k >= 0, t >= 0. Errors if k*t > conc_init (would give negative concentration). [A]t = [A]0 - k*t.

function time_to_conc_second_order(conc_init: float, conc_final: float, k: float) → float

function kc_from_kp(kp: float, t_k: float, delta_n: float) → float

function degree_of_dissociation(ka: float, conc_acid: float) → float

function gibbs_from_emf(n_electrons: float, e_cell: float) → float

kohlrausch_conductivity: molar conductivity from Kohlrausch law (S·m²/mol). Requires lambda_inf >= 0, k_const >= 0, conc >= 0. lambda_m = lambda_inf - k_const * sqrt(c).

nuclei_remaining: N(t) = N0 * exp(-lambda * t). Requires n0 >= 0, lamb_da >= 0, t >= 0. Uses unsafe_mul: N0 can be astronomically large (atom counts).

function activity_remaining(a0: float, lamb_da: float, t: float) → float

activity_remaining: A(t) = A0 * exp(-lambda * t). Requires a0 >= 0, lamb_da >= 0, t >= 0.

function radiometric_age(n0: float, n: float, lamb_da: float) → float

radiometric_age: t = ln(n0/n) / lambda. Requires n0 > 0, n > 0, lamb_da > 0. Errors if n > n0 (would give negative age — physically impossible in decay).

function carbon14_age(a0: float, a: float) → float

carbon14_age: age from specific activity ratio (years). Requires a0 > 0, a > 0, a <= a0. Errors if a > a0 (would give negative C-14 age). t = ln(a0/a) / lambda_c14.

function mass_defect(z: float, n_neutrons: float, m_proton: float, m_neutron: float, m_atom: float) → float

mass_defect: difference between constituent masses and atomic mass (u). No constraints. delta_m = Z*m_proton + N*m_neutron - m_atom.

function binding_energy(mass_defect_u: float) → float

binding_energy: nuclear binding energy (MeV). Requires mass_defect_u >= 0. E = mass_defect * 931.494 MeV/u.

function binding_energy_per_nucleon(binding_energy_mev: float, mass_number: float) → float

binding_energy_per_nucleon: binding energy per nucleon (MeV/nucleon). Requires binding_energy_mev >= 0, mass_number > 0.

function q_value_decay(m_parent: float, m_daughter: float, m_emitted: float) → float

q_value_decay: energy released in nuclear decay (MeV). No constraints. Positive Q means spontaneous decay; negative Q means energetically forbidden. Q = (m_parent - m_daughter - m_emitted) * 931.494.

function becquerel_to_curie(bq: float) → float

becquerel_to_curie: convert activity units (1 Ci = 3.7e10 Bq). Requires bq >= 0.

function curie_to_becquerel(ci: float) → float

curie_to_becquerel: convert activity units. Requires ci >= 0.

function bohr_energy(n: float) → float

function bohr_radius_n(n: float) → float

bohr_radius_n: orbital radius at quantum level n (m). rn = n^2 * a0. Requires n > 0 (quantum number, positive).

function rydberg_wavelength(n1: float, n2: float) → float

rydberg_wavelength: photon wavelength for electronic transition (m). 1/lambda = R_inf * (1/n1^2 - 1/n2^2). Requires n1 > 0, n2 > 0, n2 > n1 (emission).

function photon_energy(freq_hz: float) → float

photon_energy: energy of a photon given frequency (J). E = h * f. Requires freq_hz > 0 (photon energy must be positive).

function photon_energy_wavelength(wavelength_m: float) → float

photon_energy_wavelength: energy of a photon given wavelength (J). E = hc / lambda. Requires wavelength_m > 0 (photon energy must be positive).

function de_broglie_wavelength(mass_kg: float, velocity_ms: float) → float

de_broglie_wavelength: matter wave wavelength (m). lambda = h / (m * v). Requires mass_kg > 0, velocity_ms > 0. Uses unsafe_mul/div: quantum-scale values outside fixed-point safe range.

function heisenberg_uncertainty_x(delta_p: float) → float

heisenberg_uncertainty_x: minimum position uncertainty (m). delta_x = hbar / (2 * delta_p). Requires delta_p > 0.

function heisenberg_uncertainty_e(delta_t: float) → float

heisenberg_uncertainty_e: minimum energy uncertainty (J). delta_E = hbar / (2 * delta_t). Requires delta_t > 0.

function effective_nuclear_charge(z: float, sigma: float) → float

effective_nuclear_charge: Z_eff = Z - sigma (Slater screening). Requires z >= 0, sigma >= 0, sigma < z (result must be positive).

function ionization_energy(z_eff: float, n: float) → float

ionization_energy: energy to remove electron (eV). IE = 13.6 * Z_eff^2 / n^2. Requires z_eff > 0, n > 0.

function boiling_point_elevation(kb: float, molality: float, i: float) → float

boiling_point_elevation: delta_Tb = Kb * molality * i (°C). Requires kb > 0, molality >= 0, i >= 1 (van't Hoff factor for dissociation; use i = 1 for non-electrolytes).

function freezing_point_depression(kf: float, molality: float, i: float) → float

freezing_point_depression: delta_Tf = Kf * molality * i (°C). Requires kf > 0, molality >= 0, i >= 1.

function osmotic_pressure(molarity: float, t_k: float, i: float) → float

osmotic_pressure: pi = M * R * T * i (atm). Requires molarity >= 0, t_k > 0, i >= 1.

function raoult_law_ideal(x_solvent: float, p_pure: float) → float

raoult_law_ideal: vapour pressure of ideal solution. P_solution = x_solvent * P_pure. Requires x_solvent in [0, 1], p_pure >= 0.

function raoult_law_pressure_lowering(x_solute: float, p_pure: float) → float

raoult_law_pressure_lowering: delta_P = x_solute * P_pure. Requires x_solute in [0, 1], p_pure >= 0.

function henry_law(k_h: float, partial_pressure: float) → float

henry_law: dissolved gas concentration from partial pressure (mol/L). C = k_H * P. Requires k_h >= 0, partial_pressure >= 0.

function molarity_to_molality(molarity: float, rho_g_per_l: float, molar_mass: float) → float

molarity_to_molality: convert molarity to molality (mol/kg). m = (M * 1000) / (rho - M * molar_mass). Requires molarity >= 0, rho_g_per_l > 0, molar_mass > 0. Errors if denominator (rho - M*molar_mass) <= 0 (impossible solution density).

function mole_fraction_to_molality(x_solute: float, x_solvent: float, m_solvent_kg: float) → float

mole_fraction_to_molality: convert mole fraction to molality (mol/kg). m = x_solute / (x_solvent * M_solvent). Requires x_solute >= 0, x_solvent > 0, m_solvent_kg > 0. Errors if x_solute + x_solvent != 1 (within tolerance).

function van_t_hoff_factor_apparent(delta_t: float, k_const: float, molality: float) → float

van_t_hoff_factor_apparent: observed i from colligative property measurement. i = delta_T / (K * molality). Requires delta_t >= 0, k_const > 0, molality > 0.

function degree_of_dissociation_vant(i: float, n: float) → float

degree_of_dissociation_vant: fraction dissociated from van't Hoff factor. alpha = (i - 1) / (n - 1). Requires i >= 1, n > 1 (use only for electrolytes), i <= n (alpha must be <= 1).

function born_lande_lattice_energy(m_const: float, z_plus: float, z_minus: float, r0_m: float, n_born: float) → float

born_lande_lattice_energy: lattice energy via Born-Landé equation (J/mol). Requires m_const > 0, r0_m > 0, n_born > 1. Uses unsafe_mul: elementary charge is quantum-scale, underflows fixed-point.

function born_haber_lattice_energy(delta_hf: float, delta_hsub: float, delta_hdiss: float, ie: float, ea: float) → float

born_haber_lattice_energy: lattice energy from Born-Haber cycle (kJ/mol). No constraints. U = dHf - dHsub - dHdiss - IE - EA (Hess's law arrangement).

function kapustinskii_lattice_energy(nu_ions: float, z_plus: float, z_minus: float, r0_pm: float) → float

kapustinskii_lattice_energy: lattice energy without crystal structure (kJ/mol). Requires nu_ions >= 2, r0_pm > 0. U = (1.2025e5 * nu * |z+z-| / r0) * (1 - 0.345/r0) | r0_pm in picometres.

function crystal_field_stabilization_energy(n_t2g: float, n_eg: float, delta_o: float) → float

crystal_field_stabilization_energy: CFSE for octahedral complex (cm^-1). Requires n_t2g in [0, 6], n_eg in [0, 4], delta_o >= 0. CFSE = (-0.4*n_t2g + 0.6*n_eg) * delta_o.

function ionic_radius_ratio(r_cation: float, r_anion: float) → float

ionic_radius_ratio: rho = r_cation / r_anion (dimensionless). Requires r_cation > 0, r_anion > 0.

function pauling_ionic_character(delta_chi: float) → float

pauling_ionic_character: percent ionic character of a bond (%). %ionic = (1 - exp(-0.25*(delta_chi)^2)) * 100. No constraints (Δχ sign doesn't matter).

function madelung_energy_per_ion(m_const: float, r0_m: float) → float

madelung_energy_per_ion: electrostatic energy per ion pair (J). Requires m_const > 0, r0_m > 0. Uses unsafe_mul: elementary charge is quantum-scale, underflows fixed-point.

function degree_of_unsaturation(c_count: float, h_count: float, n_count: float) → float

degree_of_unsaturation: DoU = (2C + 2 + N - H) / 2. Halogens count as H. C >= 0, H >= 0, N >= 0. Errors if the result is non-integer (invalid formula) or negative (impossible composition).

function empirical_ratio(moles_element: float, moles_smallest: float) → float

empirical_ratio: ratio of an element's moles to the smallest mole count in the sample. moles_element >= 0, moles_smallest > 0.

function molecular_formula_multiplier(molar_mass_actual: float, empirical_formula_mass: float) → float

molecular_formula_multiplier: n = molar_mass_actual / empirical_formula_mass. Requires molar_mass_actual > 0, empirical_formula_mass > 0. Errors if result is non-integer (empirical and molecular masses are inconsistent).

function moles_from_combustion_co2(mass_co2_g: float) → float

moles_from_combustion_co2: moles of carbon in sample from CO2 produced (mol). Requires mass_co2_g >= 0. moles_C = mass_CO2 / 44.01.

function moles_from_combustion_h2o(mass_h2o_g: float) → float

moles_from_combustion_h2o: moles of hydrogen in sample from H2O produced (mol). Requires mass_h2o_g >= 0. moles_H = 2 * (mass_H2O / 18.015).

function mass_oxygen_by_difference(mass_sample_g: float, mass_c_g: float, mass_h_g: float) → float

mass_oxygen_by_difference: mass of oxygen in CHO sample (g). mass_O = mass_sample - mass_C - mass_H. Requires all masses >= 0 and mass_C + mass_H <= mass_sample.

function beer_lambert_absorbance(epsilon: float, conc: float, path_length_cm: float) → float

beer_lambert_absorbance: A = epsilon * c * l. Requires epsilon >= 0, conc >= 0, path_length_cm >= 0.

function beer_lambert_concentration(absorbance: float, epsilon: float, path_length_cm: float) → float

beer_lambert_concentration: solve for concentration from absorbance (mol/L). c = A / (epsilon * l). Requires absorbance >= 0, epsilon > 0, path_length_cm > 0.

function transmittance_from_absorbance(absorbance: float) → float

transmittance_from_absorbance: T = 10^(-A) (fraction, 0-1). Requires absorbance >= 0. Errors if result would overflow/underflow.

function absorbance_from_transmittance(transmittance: float) → float

absorbance_from_transmittance: A = -log10(T). Requires transmittance in (0, 1].

function wavelength_to_frequency(wavelength_m: float) → float

wavelength_to_frequency: f = c / lambda (Hz). Requires wavelength_m > 0.

function frequency_to_wavelength(freq_hz: float) → float

frequency_to_wavelength: lambda = c / f (m). Requires freq_hz > 0.

function wavenumber_to_wavelength(wavenumber: float) → float

wavenumber_to_wavelength: lambda = 1 / wavenumber. Requires wavenumber > 0.

function wavelength_to_wavenumber(wavelength: float) → float

wavelength_to_wavenumber: wavenumber = 1 / lambda. Requires wavelength > 0.

function energy_per_mole_photons(freq_hz: float) → float

energy_per_mole_photons: energy of one mole of photons at given frequency (J/mol). Requires freq_hz > 0. E_mol = N_A * h * f. Uses unsafe_mul: N_A is astronomically large.
