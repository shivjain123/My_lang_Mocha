function mean_arterial_pressure(systolic: float, diastolic: float) → float

MAP = diastolic + (1/3 * pulse_pressure). Normal range: 70-100 mmHg.

function pulse_pressure(systolic: float, diastolic: float) → float

Pulse pressure = systolic - diastolic. Normal range: 40 mmHg. > 60 mmHg suggests aortic stiffness.

function cardiac_output(heart_rate: float, stroke_volume: float) → float

Cardiac output = heart_rate * stroke_volume / 1000. Result in L/min. Normal range: 4-8 L/min.

function cardiac_index(cardiac_output: float, body_surface_area: float) → float

Cardiac index = cardiac_output / body_surface_area. Result in L/min/m². Normal range: 2.5-4.0 L/min/m².

function ejection_fraction(stroke_volume: float, end_diastolic_volume: float) → float

Ejection fraction = (stroke_volume / end_diastolic_volume) * 100. Result in %. Normal: >= 55%. Reduced: < 40%.

function stroke_volume(end_diastolic: float, end_systolic: float) → float

Stroke volume = end_diastolic_volume - end_systolic_volume. Result in mL.

function body_surface_area(weight_kg: float, height_cm: float) → float

Body surface area — Mosteller formula. BSA = sqrt((weight_kg * height_cm) / 3600). Result in m².

function rate_pressure_product(heart_rate: float, systolic: float) → float

Rate pressure product = heart_rate * systolic. Indicator of myocardial oxygen demand. > 20000 indicates high cardiac stress.

function aortic_size_index(aortic_diameter_cm: float, body_surface_area: float) → float

Aortic size index = aortic_diameter_cm / body_surface_area. Result in cm/m². > 2.75 cm/m² indicates high risk of aortic dissection.

function svr(map: float, cvp: float, cardiac_output: float) → float

Systemic vascular resistance = ((MAP - CVP) / cardiac_output) * 80. Result in dynes·s/cm⁵. Normal range: 800–1200 dynes·s/cm⁵. CVP (central venous pressure) normal range: 2–8 mmHg.

function qtc_bazett(qt_ms: float, heart_rate: float, sex: Sex) → float

QTc (Bazett) = QT_ms / sqrt(RR_s). where RR_s = 60.0 / heart_rate (in seconds). Result in ms. Normal: < 440 ms (male), < 460 ms (female). > 500 ms: high risk of torsades de pointes.

function shock_index(heart_rate: float, systolic: float) → float

Shock index = heart_rate / systolic_pressure. Normal: 0.5–0.7. > 1.0: significant haemodynamic compromise. > 1.4: critical — consider immediate intervention.

function vo2_max_fick(cardiac_output: float, cao2: float, cvo2: float) → float

VO2 max (Fick) = cardiac_output * (cao2 - cvo2). cao2: arterial oxygen content (mL O₂ / dL blood). cvo2: mixed venous oxygen content (mL O₂ / dL blood). cardiac_output in L/min → multiply by 10 to convert dL. Result in mL O₂/min. Normal a-vO₂ difference at rest: 4–6 mL O₂/dL. At peak exercise: up to 15–16 mL O₂/dL.

function framingham_risk(age: float, sex: Sex, total_cholesterol: float, hdl_cholesterol: float, systolic: float, bp_treated: bool, smoking: SmokingStatus) → float

Framingham 10-year Hard CHD risk (D'Agostino et al.). Uses natural log of inputs — do NOT pass pre-logged values. total_cholesterol, hdl_cholesterol in mg/dL. systolic in mmHg, age in years (valid range: 30–79). bp_treated: true if patient is on BP medication. Non-diabetic patients only — excludes angina pectoris history. Returns risk as a percentage (0.0–100.0).

function ideal_body_weight(height_cm: float, sex: Sex) → float

Ideal body weight (Devine formula). Male: IBW = 50.0 + 2.3 * ((height_cm / 2.54) - 60). Female: IBW = 45.5 + 2.3 * ((height_cm / 2.54) - 60). Result in kg. Valid for height > 152.4 cm (5 feet) — below this IBW = actual weight.

function tidal_volume(ibw_kg: float) → float

Tidal volume = 6-8 mL/kg IBW (lung protective ventilation). Uses 6 mL/kg — ARDSnet lower limit, safest default. Result in mL. Normal spontaneous tidal volume: 400-600 mL.

function minute_ventilation(tidal_volume_ml: float, respiratory_rate: float) → float

Minute ventilation = tidal_volume * respiratory_rate. Result in L/min. Normal range: 5-10 L/min.

function alveolar_po2(fio2: float, patm: float, paco2: float, rq: float) → float

Alveolar partial pressure of oxygen. PAO2 = FiO2 * (Patm - PH2O) - (PaCO2 / RQ). PH2O = 47 mmHg at body temperature (constant). Result in mmHg. Exposed standalone — useful independently of A-a gradient.

function aa_gradient(fio2: float, patm: float, paco2: float, pao2: float, rq: float) → float

Alveolar-arterial oxygen gradient. A-a gradient = PAO2 - PaO2. Normal range: increases with age — roughly (age / 4) mmHg. > 15 mmHg on room air suggests V/Q mismatch or shunt.

function fev1_fvc_ratio(fev1: float, fvc: float) → float

FEV1/FVC ratio. FEV1: forced expiratory volume in 1 second (L). FVC: forced vital capacity (L). < 0.70 suggests obstructive pattern (asthma, COPD). >= 0.70 with reduced FVC suggests restrictive pattern.

function dead_space_fraction(paco2: float, peco2: float) → float

Dead space fraction (Bohr equation). Vd/Vt = (PaCO2 - PECO2) / PaCO2. PaCO2: arterial CO2 (mmHg). PECO2: mixed expired CO2 (mmHg). Normal: 0.2-0.35 (20-35% of tidal volume is dead space). > 0.6 associated with poor outcomes in ARDS.

function lung_compliance(tidal_volume_ml: float, plateau_pressure: float, peep: float) → float

Static lung compliance. C = tidal_volume / (plateau_pressure - peep). Result in mL/cmH2O. Normal: 60-100 mL/cmH2O. < 40 mL/cmH2O suggests stiff lungs (ARDS, pulmonary fibrosis).

function pf_ratio(pao2: float, fio2: float) → float

PaO2/FiO2 ratio (P/F ratio). Result in mmHg. Normal > 300.

function ards_severity(pf: float) → ArdsSeverity

ARDS severity classifier — Berlin criteria. Pass result of pf_ratio() directly. > 300: no ARDS. 200-300: mild. 100-200: moderate. < 100: severe.

function oxygen_content(hgb: float, sao2: float, pao2: float) → float

Oxygen content of blood (CaO2). CaO2 = (Hgb * 1.34 * SaO2) + (0.0031 * PaO2). Hgb in g/dL, SaO2 as fraction (0.0-1.0), PaO2 in mmHg. Result in mL O2/dL blood. 1.34 = Hüfner constant (O2 carrying capacity per gram Hgb). 0.0031 = dissolved O2 coefficient. Normal arterial: ~20 mL O2/dL.

function gcs(eye: GcsEye, verbal: GcsVerbal, motor: GcsMotor) → GcsSeverity

Glasgow Coma Scale. Total score 3–15. Severe: 3–8, Moderate: 9–12, Mild: 13–15. Score of 3 = no response in any component — deep coma or death. Score of 8 or below = unable to protect airway — intubation threshold.

function gcs_score(eye: GcsEye, verbal: GcsVerbal, motor: GcsMotor) → int

GCS total score — returns raw int if caller needs the number.

function cerebral_perfusion_pressure(map: float, icp: float) → float

Cerebral perfusion pressure. CPP = MAP - ICP. Result in mmHg. Normal: 60–80 mmHg. < 60 mmHg: cerebral ischaemia risk. < 40 mmHg: severe — incompatible with consciousness.

function cerebral_blood_flow(cmro2: float, avdo2: float) → float

Cerebral blood flow (Fick principle). CBF = CMRO2 / AVDO2. CMRO2: cerebral metabolic rate of O2 in mL O2/100g/min. AVDO2: arteriovenous O2 difference in mL O2/100mL blood. Result in mL/100g/min. Normal CBF: 50–60 mL/100g/min. < 20 mL/100g/min: ischaemic threshold. < 10 mL/100g/min: infarction threshold.

function serum_osmolality(na: float, glucose: float, bun: float) → float

Serum osmolality. Osm = 2*Na + glucose/18 + BUN/2.8. Na in mEq/L, glucose in mg/dL, BUN in mg/dL. Result in mOsm/kg. Normal: 275–295 mOsm/kg. > 320 mOsm/kg: hyperosmolar state.

function osmolar_gap(measured_osm: float, calculated_osm: float) → float

Osmolar gap. Gap = measured_osm - calculated_osm. calculated_osm should be from serum_osmolality(). Normal: < 10 mOsm/kg. > 10 mOsm/kg: suggests unmeasured osmoles — toxic alcohols, mannitol.

function corrected_sodium(na: float, glucose: float) → float

Corrected sodium for hyperglycaemia. Corrected Na = Na + 0.016 * (glucose - 100). Na in mEq/L, glucose in mg/dL. Accounts for osmotic shift of water out of cells in hyperglycaemia. Each 100 mg/dL rise in glucose above normal drops Na by ~1.6 mEq/L.

function ckd_epi_gfr(serum_cr: float, age: float, sex: Sex) → CkdStage

CKD-EPI GFR (2021 — no race coefficient). Serum creatinine in mg/dL, age in years. Result in mL/min/1.73m². G1: >= 90, G2: 60-89, G3a: 45-59, G3b: 30-44, G4: 15-29, G5: < 15.

function ckd_epi_gfr_value(serum_cr: float, age: float, sex: Sex) → float

CKD-EPI GFR raw value — returns float if caller needs the number. Same inputs as ckd_epi_gfr().

function cockcroft_gault(age: float, weight_kg: float, serum_cr: float, sex: Sex) → float

Cockcroft-Gault creatinine clearance. CrCl = ((140 - age) * weight_kg) / (72 * serum_cr). Multiply by 0.85 for females. Result in mL/min. Used for drug dosing — not interchangeable with CKD-EPI GFR.

function bun_creatinine_ratio(bun: float, serum_cr: float) → float

BUN/creatinine ratio. Both in mg/dL. Normal: 10-20. > 20: prerenal (dehydration, GI bleeding, high protein intake). < 10: intrinsic renal disease, liver failure, low protein intake.

function fena(urine_na: float, serum_cr: float, serum_na: float, urine_cr: float) → AkiLikelihood

Fractional excretion of sodium (FENa). FENa = (urine_na * serum_cr) / (serum_na * urine_cr) * 100. All sodium in mEq/L, creatinine in mg/dL. Result in %. < 1%: prerenal AKI (kidneys conserving sodium). > 2%: intrinsic renal AKI (tubular damage). 1-2%: indeterminate. Unreliable in patients on diuretics — use FEUrea instead.

function fena_value(urine_na: float, serum_cr: float, serum_na: float, urine_cr: float) → float

FENa raw value — returns float if caller needs the number.

function feurea(urine_urea: float, serum_cr: float, serum_urea: float, urine_cr: float) → AkiLikelihood

Fractional excretion of urea (FEUrea). FEUrea = (urine_urea * serum_cr) / (serum_urea * urine_cr) * 100. All urea in mg/dL, creatinine in mg/dL. Result in %. < 35%: prerenal AKI. >= 35%: intrinsic renal AKI. Use when patient is on diuretics — FENa unreliable in that context.

function feurea_value(urine_urea: float, serum_cr: float, serum_urea: float, urine_cr: float) → float

FEUrea raw value — returns float if caller needs the number.

function urine_specific_gravity(density_urine: float, density_water: float) → float

Urine specific gravity from solute and solvent densities. SG = density_urine / density_water.

function urine_sg_interpretation(sg: float) → UrineSGInterpretation

Interpret urine specific gravity value.

function urine_sg_message(sg: float) → str

Clinical message for urine SG interpretation.

function body_adiposity_index(hip_cm: float, height_cm: float) → float

Body adiposity index (BAI). BAI = (hip_cm / height_cm^1.5) - 18. Estimates body fat % directly. Normal: ~21-33% women, ~8-21% men. More accurate than BMI for estimating adiposity.

function ponderal_index(weight_kg: float, height_cm: float) → float

Ponderal index. PI = weight_kg / (height_m^3). Less sensitive to height extremes than BMI. Normal range: 11-15 kg/m³.

function waist_height_ratio(waist_cm: float, height_cm: float) → WaistHeightRisk

Waist-to-height ratio. WHtR = waist_cm / height_cm. One of the strongest individual predictors of cardiometabolic risk. < 0.4: low. 0.4-0.5: moderate. 0.5-0.6: high. > 0.6: very high.

function waist_height_ratio_value(waist_cm: float, height_cm: float) → float

Waist-to-height ratio raw value.

function relative_fat_mass(height_cm: float, waist_cm: float, sex: Sex) → float

Relative fat mass (RFM) — Woolcott & Bergman 2018. Male: RFM = 64 - (20 * height_cm / waist_cm). Female: RFM = 76 - (20 * height_cm / waist_cm). Result in % body fat. Designed specifically to replace BMI for individual assessment. Normal: ~6-24% men, ~14-36% women.

function basal_metabolic_rate(weight_kg: float, height_cm: float, age: float, sex: Sex) → float

Basal metabolic rate — Mifflin-St Jeor equation. Male: BMR = (10 * weight_kg) + (6.25 * height_cm) - (5 * age) + 5. Female: BMR = (10 * weight_kg) + (6.25 * height_cm) - (5 * age) - 161. Result in kcal/day. Most accurate BMR formula for general population.

function total_daily_energy_expenditure(bmr: float, activity: ActivityLevel) → float

Total daily energy expenditure. TDEE = BMR * activity_multiplier. Result in kcal/day. Sedentary: 1.2, Light: 1.375, Moderate: 1.55, Active: 1.725, Very active: 1.9.

function hba1c_to_eag(hba1c: float) → float

HbA1c to estimated average glucose (eAG). eAG = (HbA1c * 28.7) - 46.7. HbA1c in %, result in mg/dL. Normal HbA1c: < 5.7%. Prediabetes: 5.7-6.4%. Diabetes: >= 6.5%.

function homa_ir(fasting_glucose: float, fasting_insulin: float) → float

HOMA-IR — homeostatic model assessment of insulin resistance. HOMA-IR = (fasting_glucose_mg_dl * fasting_insulin_uU_ml) / 405. Normal: < 1.0 (insulin sensitive). > 1.9: early insulin resistance. > 2.9: significant insulin resistance.

function corrected_calcium(measured_calcium: float, albumin: float) → float

Corrected calcium for hypoalbuminaemia. Corrected Ca = measured_calcium + 0.8 * (4.0 - albumin). Calcium in mg/dL, albumin in g/dL. Normal corrected calcium: 8.5-10.5 mg/dL. Hypoalbuminaemia falsely lowers measured calcium.

function free_water_deficit(weight_kg: float, sodium: float, sex: Sex) → float

Free water deficit. FWD = body_water_fraction * weight_kg * (sodium / 140.0 - 1.0). Body water fraction: 0.6 male, 0.5 female. Result in litres. Used in hypernatraemia management to estimate free water replacement. > 5L: severe deficit.

function elimination_rate_constant(cl: float, vd: float) → float

Elimination rate constant. ke = CL / Vd. CL in L/h, Vd in L. Result in h⁻¹. Describes the fraction of Vd cleared per unit time.

function half_life(ke: float) → float

Half-life. t½ = ln(2) / ke = 0.693 / ke. ke in h⁻¹, result in hours. Time for plasma concentration to halve.

function half_life_from_cl_vd(cl: float, vd: float) → float

Half-life from CL and Vd directly. t½ = (ln(2) * Vd) / CL. Convenience function — avoids caller computing ke manually.

function volume_of_distribution(dose_mg: float, c0: float) → float

Volume of distribution. Vd = dose / C0. dose in mg, C0 in mg/L (initial plasma concentration after IV bolus). Result in L. Apparent volume into which drug distributes.

function clearance(ke: float, vd: float) → float

Clearance. CL = ke * Vd. ke in h⁻¹, Vd in L. Result in L/h. Volume of plasma cleared of drug per unit time.

function loading_dose(vd: float, target_concentration: float) → float

Loading dose. LD = Vd * target_concentration. Vd in L, target_concentration in mg/L. Result in mg. Dose required to immediately achieve target plasma concentration.

function maintenance_dose(cl: float, target_concentration: float, tau: float) → float

Maintenance dose. MD = CL * target_concentration * tau. CL in L/h, target_concentration in mg/L, tau (dosing interval) in hours. Result in mg. Dose required to maintain target steady state concentration.

function bioavailability_adjusted_dose(intended_dose: float, f: float, route: RouteOfAdministration) → float

Bioavailability-adjusted dose. Adjusted dose = intended_dose / F. F: bioavailability fraction (0.0-1.0). IV route: F = 1.0 by definition. Oral/other routes: F < 1.0 due to first-pass and absorption losses.

function concentration_at_time(c0: float, ke: float, t: float) → float

One-compartment concentration at time t. C(t) = C0 * e^(-ke * t). C0 in mg/L, ke in h⁻¹, t in hours. Result in mg/L. Assumes instantaneous distribution (IV bolus).

function steady_state_concentration(f: float, dose_mg: float, cl: float, tau: float) → float

Steady state concentration. Css = (F * dose) / (CL * tau). F: bioavailability, dose in mg, CL in L/h, tau in hours. Result in mg/L. Average plasma concentration at steady state. Reached after ~4-5 half-lives.

function accumulation_factor(ke: float, tau: float) → float

Accumulation factor. R = 1 / (1 - e^(-ke * tau)). ke in h⁻¹, tau (dosing interval) in hours. Dimensionless — predicts ratio of steady state to first dose concentration. R = 1: no accumulation (tau >> t½). R >> 1: significant accumulation (tau << t½).

function hill_effect(c: float, emax: float, ec50: float, n: float) → float

Hill equation (Emax model). E = Emax * C^n / (EC50^n + C^n). Emax: maximum effect (same units as E). C: drug concentration in mg/L. EC50: concentration producing 50% Emax in mg/L. n: Hill coefficient (dimensionless). n = 1: hyperbolic (simple binding). n > 1: sigmoidal (cooperative binding). n < 1: shallow curve (heterogeneous receptors). Result in same units as Emax.

function hill_concentration(e: float, emax: float, ec50: float, n: float) → float

Hill equation inverse — concentration to achieve target effect. C = EC50 * (E / (Emax - E))^(1/n). E must be strictly between 0 and Emax. Result in mg/L.

function mcv(hematocrit: float, rbc: float) → AnaemiaType

Mean corpuscular volume (MCV). MCV = (hematocrit * 10) / RBC_count. Hematocrit in %, RBC in x10⁶/µL. Result in fL (femtolitres). Normal: 80-100 fL. < 80: microcytic (iron deficiency, thalassaemia). > 100: macrocytic (B12/folate deficiency).

function mcv_value(hematocrit: float, rbc: float) → float

MCV raw value.

function mch(hgb: float, rbc: float) → float

Mean corpuscular haemoglobin (MCH). MCH = (Hgb * 10) / RBC_count. Hgb in g/dL, RBC in x10⁶/µL. Result in pg (picograms). Normal: 27-33 pg.

function mchc(hgb: float, hematocrit: float) → float

Mean corpuscular haemoglobin concentration (MCHC). MCHC = (Hgb / hematocrit) * 100. Hgb in g/dL, hematocrit in %. Result in g/dL. Normal: 32-36 g/dL. < 32: hypochromic (iron deficiency). > 36: hyperchromic (spherocytosis, severe dehydration).

function corrected_reticulocyte(retic_pct: float, hematocrit: float, sex: Sex) → float

Corrected reticulocyte count. Corrected retic% = retic% * (hematocrit / normal_hct). Normal Hct: 45% male, 41% female. Corrects for dilutional effect of anaemia on reticulocyte percentage. Normal corrected retic: 1-2%.

function reticulocyte_production_index(retic_pct: float, hematocrit: float, sex: Sex) → float

Reticulocyte production index (RPI). RPI = corrected_retic / maturation_factor. Maturation factor derived internally from hematocrit: Hct >= 36%: 1.0, Hct 26-35%: 1.5, Hct 16-25%: 2.0, Hct < 16%: 2.5. RPI < 2: hypoproliferative (bone marrow not responding). RPI >= 2: adequate response (haemolysis or blood loss).

function blood_volume(height_cm: float, weight_kg: float, sex: Sex) → float

Blood volume estimation (Nadler equation). Male: BV = (0.3669 * height_m^3) + (0.03219 * weight_kg) + 0.6041. Female: BV = (0.3561 * height_m^3) + (0.03308 * weight_kg) + 0.1833. Result in litres. Normal: ~5L male, ~4L female.

function anc(wbc: float, neutrophils_pct: float, bands_pct: float) → NeutropeniaGrade

Absolute neutrophil count (ANC). ANC = WBC * (neutrophils_pct + bands_pct) / 100. WBC in x10³/µL, percentages 0-100. Result in x10³/µL. Normal: >= 1.5 x10³/µL. Mild neutropenia: 1.0-1.5. Moderate: 0.5-1.0. Severe: < 0.5 — high infection risk.

function anc_value(wbc: float, neutrophils_pct: float, bands_pct: float) → float

ANC raw value.

function transferrin_saturation(serum_iron: float, tibc: float) → float

Transferrin saturation. Tsat = (serum_iron / TIBC) * 100. Both in µg/dL, result in %. Normal: 20-50%. < 20%: iron deficiency. > 50%: iron overload (haemochromatosis).

function rule_of_nines(head: float, chest: float, abdomen: float, left_arm: float, right_arm: float, left_leg: float, right_leg: float, perineum: float) → float

Rule of Nines — estimates total body surface area burned (% TBSA). Each param is the percentage of THAT region that is burned (0-100). Weightings: head=9%, chest=18%, abdomen=18%, left_arm=9%, right_arm=9%, left_leg=18%, right_leg=18%, perineum=1%.

function parkland(weight_kg: float, tbsa_burned: float) → float

Parkland formula — total IV fluid (mL) in first 24 hours post-burn. Standard: 4 mL * weight_kg * %TBSA_burned. First half given in first 8 hours, second half over next 16 hours. Returns total 24hr volume in mL.

function parkland_first_8hr_rate(weight_kg: float, tbsa_burned: float) → float

Parkland first 8 hours — mL/hr rate for first 8 hours.

function parkland_next_16hr_rate(weight_kg: float, tbsa_burned: float) → float

Parkland next 16 hours — mL/hr rate for hours 8-24.

function burn_severity(tbsa: float) → BurnSeverity

No documentation.

function drip_rate_gtt_min(volume_ml: float, time_hr: float, drop_factor: float) → float

Drip rate in gtt/min. drop_factor: drops per mL (typically 10, 15, 20 for macrodrip; 60 for microdrip).

function infusion_time_hr(volume_ml: float, rate_ml_hr: float) → float

Infusion time in hours given volume and rate.

function volume_to_infuse(rate_ml_hr: float, time_hr: float) → float

Total volume to infuse given rate and time.

function mcg_kg_min_to_ml_hr(dose_mcg_kg_min: float, weight_kg: float, concentration_mcg_ml: float) → float

Convert mcg/kg/min dose to mL/hr pump rate. e.g. norepinephrine, dopamine, dobutamine, propofol.

function ml_hr_to_mcg_kg_min(rate_ml_hr: float, weight_kg: float, concentration_mcg_ml: float) → float
